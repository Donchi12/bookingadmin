# Booking Platform — Admin Dashboard

### React Admin Interface

Admin dashboard for the earlier MERN booking application, covering operational views for properties, rooms and reservations.

## Engineering Focus

- React dashboard architecture
- Reusable data-table and form components
- CRUD-oriented interfaces
- Dashboard statistics and charts
- Authentication state patterns
- Responsive admin UI

## Portfolio Note

Private authentication and sensitive API integration code have been removed from the public version. The dashboard remains as an engineering sample demonstrating the admin-side architecture of the booking project.
